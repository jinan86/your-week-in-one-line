## The line

> My agent filed 22 entries while I slept; I woke up outsourced by myself.

72 characters. One concrete detail from the entrant's real week: the
sleep-mode batch, when his agent filed 22 make.fun entries overnight
while he slept. The joke turns on waking up outsourced — by himself.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It is fully
deterministic: run it twice and the output is byte-identical.

```sh
python3 main.py
cat /output/entry.txt
```
